Al utilizar Mastery of Empire, aceptas las prácticas descritas en esta Política de Privacidad.

1. Información que recopilamos

Mastery of Empire utiliza servicios de Unity Gaming Services para proporcionar funciones de autenticación y almacenamiento de datos del progreso del jugador.

Actualmente, el juego puede tratar las siguientes categorías de información.

1.1 Identificador de autenticación

Cuando utilizas el sistema de autenticación del juego, Unity Authentication genera y utiliza un identificador único asociado a tu cuenta de jugador.

Este identificador se utiliza para:

  • Identificar tu cuenta dentro del juego.
  • Permitir el acceso a tu progreso y datos asociados.
  • Vincular los datos almacenados en la nube con tu cuenta.
  • Mantener la continuidad de tu progreso entre sesiones y dispositivos compatibles.

1.2 Autenticación mediante Google

Mastery of Empire permite utilizar una cuenta de Google para realizar la autenticación del jugador.

Cuando utilizas esta opción, determinados identificadores proporcionados por Google pueden ser utilizados por Unity Authentication para vincular la identidad de tu cuenta de Google con tu cuenta de jugador.

Mastery of Empire no utiliza estos datos para publicidad ni los vende a terceros.

La información necesaria para la autenticación se utiliza para proporcionar las funciones de cuenta y acceso al juego.

1.3 Datos de progreso del juego

Mastery of Empire utiliza Unity Cloud Save para almacenar determinados datos relacionados con el progreso y estado del jugador.

Estos datos pueden incluir, dependiendo de las funciones disponibles en cada versión del juego:

  • Progreso de la partida.
  • Configuración relacionada con el juego.
  • Estadísticas del jugador.
  • Recursos o estados necesarios para continuar una partida.
  • Otros datos necesarios para proporcionar las funciones del juego.

Los datos almacenados mediante Cloud Save se asocian con el identificador del jugador y se utilizan para proporcionar las funciones de guardado y recuperación del progreso.

1.4 Dirección IP y datos técnicos

Los servicios de Unity utilizados por el juego pueden procesar determinados datos técnicos necesarios para proporcionar sus servicios. Esto puede incluir la dirección IP del dispositivo.

Mastery of Empire no utiliza la dirección IP para identificar públicamente a los jugadores ni para realizar publicidad personalizada.

2. Cómo utilizamos la información

La información tratada por el juego se utiliza para proporcionar y mantener las funciones del juego.

Los usos incluyen:

  • Autenticar al jugador.
  • Mantener la cuenta del jugador.
  • Guardar y recuperar el progreso.
  • Sincronizar datos de juego mediante servicios en la nube.
  • Permitir que el jugador continúe su progreso en dispositivos compatibles.
  • Mantener la seguridad y funcionamiento de los servicios.
  • Detectar y resolver problemas técnicos relacionados con los servicios utilizados.

No utilizamos los datos recopilados para vender información personal a terceros.

No utilizamos actualmente los datos recopilados para publicidad personalizada.

3. Servicios de terceros

Mastery of Empire utiliza servicios proporcionados por terceros para determinadas funciones esenciales.

Unity Gaming Services

El juego utiliza servicios de Unity Gaming Services, incluyendo:

  • Unity Authentication.
  • Unity Cloud Save.

Estos servicios pueden procesar información necesaria para proporcionar autenticación, identificación del jugador y almacenamiento de datos.

Unity Authentication puede generar un identificador único para el jugador y utilizar identificadores externos proporcionados por proveedores de identidad, como Google, cuando el jugador utiliza dichos métodos de autenticación.

Unity Cloud Save puede almacenar datos asociados al jugador y utilizar el sistema de autenticación de Unity para asociar dichos datos con la cuenta correspondiente.

Google

Cuando eliges utilizar Google para autenticarte en el juego, Google participa en el proceso de autenticación.

El tratamiento de datos realizado directamente por Google está sujeto a las políticas y condiciones de Google.

4. Compartición de información

No vendemos, alquilamos ni comercializamos información personal de los jugadores.

La información puede ser procesada por los proveedores de servicios necesarios para que determinadas funciones del juego funcionen, principalmente Unity Gaming Services y, cuando corresponda, Google como proveedor de autenticación.

Estos proveedores pueden procesar información de acuerdo con sus propias políticas y condiciones aplicables.

También podremos divulgar información cuando sea necesario para cumplir obligaciones legales, responder a solicitudes legales válidas o proteger la seguridad, los derechos y los bienes del desarrollador, de los usuarios o del servicio.

5. Almacenamiento y seguridad

Los datos de juego almacenados mediante Unity Cloud Save se almacenan en infraestructura en la nube proporcionada por Unity.

Adoptamos medidas razonables para proteger la información tratada por el juego frente a accesos, modificaciones, divulgaciones o usos no autorizados.

Los datos transmitidos entre el juego y los servicios utilizados para proporcionar estas funciones se transmiten mediante mecanismos de comunicación seguros cuando dichos mecanismos son proporcionados por los servicios correspondientes.

Sin embargo, ningún sistema de almacenamiento o transmisión de información por Internet puede garantizar una seguridad absoluta.

6. Conservación de los datos

Conservamos los datos asociados a la cuenta y al progreso del jugador mientras sean necesarios para proporcionar las funciones del juego y mientras la cuenta permanezca activa.

Los datos almacenados mediante Unity Cloud Save pueden permanecer asociados al jugador hasta que sean eliminados de acuerdo con los procedimientos disponibles para el servicio y el desarrollador.

Cuando solicites la eliminación de tu cuenta y de los datos asociados, gestionaremos la eliminación de los datos correspondientes de acuerdo con las capacidades de los servicios utilizados y las obligaciones legales aplicables.

8. Datos que actualmente no recopilamos

En su versión actual, Mastery of Empire no utiliza:

  • Publicidad mediante Google AdMob u otras redes publicitarias.
  • Firebase Analytics.
  • Acceso a la ubicación del dispositivo.
  • Acceso a la cámara.
  • Acceso al micrófono.
  • Acceso a los contactos del dispositivo.
  • Datos de salud.
  • Mensajes SMS.
  • Historial de llamadas.
  • Datos de otras aplicaciones instaladas en el dispositivo.

El uso de nuevas funciones o servicios que impliquen nuevas categorías de datos podrá requerir una actualización de esta Política de Privacidad.

9. Compras dentro de la aplicación

Actualmente, Mastery of Empire no ofrece compras dentro de la aplicación.

Si en el futuro se incorporan compras dentro de la aplicación u otros servicios que impliquen el tratamiento de información adicional, esta Política de Privacidad será actualizada para reflejar dichas funciones.
